# Test Plan

## Project
Demoblaze E-commerce Web Application

## Objective
Validate the functional behavior, usability, reliability and basic integration of the Demoblaze e-commerce application.

## Scope

### In Scope
- User registration
- User login
- Product categories
- Product listing
- Product details
- Shopping cart
- Order placement
- Logout

### Out of Scope
- Backend/server infrastructure
- Payment gateway integration beyond the available demo flow
- Performance/load testing
- Security penetration testing

## Testing Types
- Functional Testing
- Smoke Testing
- Sanity Testing
- Regression Testing
- Integration Testing
- Negative Testing
- Boundary Value Analysis
- Equivalence Partitioning
- Exploratory Testing
- UI/Usability Testing

## Test Environment

Application: Demoblaze  
Application Type: Web  
Browsers: Chrome, Edge  
Operating System: Windows

## Entry Criteria
- Application is accessible
- Test environment is available
- Required functionality is deployed

## Exit Criteria
- Planned test cases executed
- Critical/High severity defects addressed or documented
- Regression testing completed
- Test summary prepared

## Deliverables
- Test Plan
- Test Scenarios
- Test Cases
- Defect Reports
- RTM
- Test Execution Report
- Test Summary Report
